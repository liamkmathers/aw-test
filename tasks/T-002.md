# T-002: Fix CI typecheck ordering and sync workflow files to plugin 0.1.2

## Context

`npx tsc --noEmit` fails on a clean install because Next 16 generates `LayoutProps` (and the rest of `.next/types`) during typegen, which has not run yet at that point. Both `.agent-workflow` and `.github/workflows/pr.yml` invoke the bare `tsc` command, so a fresh clone and CI both fail before any real type error is reached. Separately, agent-workflow plugin 0.1.2 changed the CLAUDE.md workflow section, added a Pruning section to the REVIEW.md template, and replaced `assess` with `chore` in the task template's `kind` line; this repo is still on the pre-0.1.2 wording.

## Acceptance criteria

- [x] The `typecheck:` line in `.agent-workflow` is exactly `npx next typegen && npx tsc --noEmit`
- [x] `.github/workflows/pr.yml` runs `npx next typegen && npx tsc --noEmit` in place of the `npx tsc --noEmit` step
- [x] The `## Workflow (every task)` section of `CLAUDE.md` matches https://raw.githubusercontent.com/liamkmathers/agent-workflow/main/plugins/agent-workflow/templates/CLAUDE.workflow.md exactly
- [x] `REVIEW.md` contains the Pruning section from the 0.1.2 template
- [x] The `kind:` line in `tasks/TEMPLATE.md` matches the 0.1.2 template (`feature | fix | chore`)
- [x] `npx next typegen && npx tsc --noEmit` exits 0 on a clean tree
- [x] Existing tests pass

- App code under `app/`
- Tests under `tests/`
- `.dependency-cruiser.cjs` rules
- The `## Things Claude gets wrong` section of CLAUDE.md (below the Workflow section, repo-local)
